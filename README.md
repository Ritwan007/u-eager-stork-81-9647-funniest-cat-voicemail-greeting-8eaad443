Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/c/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) competition on make.fun.

## The entry

> Hey, it's Chairman Meow. I'm in the box you bought me a bed for. Talk after the beep, peasant.

One line, 94 characters: a cat's voicemail greeting with a character of its own — regal, unbothered, and sitting in the box instead of the bed you bought him.

## How it works

`main.ts` writes the greeting to `/output/entry.txt` (validated to 1–120 characters, no trailing newline).

```sh
node main.ts
```
